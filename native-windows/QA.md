## 修复过并复测的问题

- OOXML 关系类型由命名空间对象拼接导致非法 XML 名称，改为 URI 字符串。
- 字体元素顺序不符合 Open XML，修正后官方验证通过。
- ExcelJS 解析依赖绘图命名空间前缀及图片文件名形式，采用常见的 `xdr` / `a` / `r` 和纯字母数字资源名。
- 原生 UI 的草稿丢弃会重新载入磁盘内容，避免后续取消操作留下错误的“已保存”状态。
- SplitContainer 初始化先设置尺寸再设分隔位置，避免默认小尺寸与分隔距离冲突。
